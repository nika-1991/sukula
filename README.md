# 🌱 სუკულა — სუკულენტების მაღაზია

ინტერაქტიული მაღაზია, სადაც კლიენტი თავად აწყობს სუკულენტს (მცენარე + ქოთანი + შეფუთვა),
ხედავს ცოცხალ პრევიუს და აფორმებს შეკვეთას. აქვს ადმინ-პანელი, მონაცემთა ბაზა,
იმეილ-შეტყობინებები და შეკვეთების ექსელად ჩამოტვირთვა.

## რა შედის

- **მაღაზია** (`/`) — კონფიგურატორი, კალათა, შეკვეთის გაფორმება
- **ადმინი** (`/admin`) — პროდუქტების (ქოთნები, ყვავილები, ფასები) დამატება/რედაქტირება/წაშლა; შეკვეთების ნახვა და ექსელად ჩამოტვირთვა
- **ბაზა** — SQLite (ფაილი: `data/shop.db`)
- **იმეილი** — ყოველ შეკვეთაზე დეტალები იგზავნება მითითებულ მისამართზე

---

## გაშვება (ნაბიჯ-ნაბიჯ)

### 1. დააინსტალირე Node.js
ჩამოტვირთე [nodejs.org](https://nodejs.org)-დან (ვერსია 18 ან უფრო ახალი).

### 2. გახსენი საქაღალდე და დააინსტალირე პაკეტები
```bash
cd sukula
npm install
```

### 3. გამართე კონფიგი
დააკოპირე `.env.example` და დაარქვი `.env`, შემდეგ შეავსე:
```bash
cp .env.example .env
```
სავალდებულოა შეცვალო `ADMIN_PASSWORD` და `SESSION_SECRET`.

### 4. გაუშვი
```bash
npm start
```
გაიხსნება:
- მაღაზია: **http://localhost:3000**
- ადმინი: **http://localhost:3000/admin**

## იმეილის გამართვა (Gmail მაგალითი)

1. Google ანგარიშში ჩართე **2-Step Verification**
2. შექმენი **App Password** (Google Account → Security → App passwords)
3. `.env`-ში ჩაწერე:
   ```
   ORDER_EMAIL=sheni@gmail.com
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=sheni@gmail.com
   SMTP_PASS=16-niSniani-app-password
   ```

სხვა პროვაიდერისთვის (შენი დომენის ფოსტა, Outlook და ა.შ.) უბრალოდ შესაბამისი
SMTP მონაცემები ჩაწერე. თუ SMTP არ გაქვს გამართული, შეკვეთები მაინც შეინახება ბაზაში.

## პროდუქტების მართვა

ადმინში, **„პროდუქტები"** ჩანართზე:
- **მცენარე** — სახელი, ფასი, ვიზუალი (ფორმის არჩევა), სიმაღლე/განათება/მორწყვა
- **ქოთანი** — სახელი, ფასი, ფერი (ფერის არჩევით ვიზუალიც იცვლება)
- **შეფუთვა** — სახელი, ფასი, სტილი (უბრალო / ქრაფტ / სასაჩუქრე)

„აქტიური = არა"-ზე დაყენებული პროდუქტი მაღაზიაში არ გამოჩნდება.

## ინტერნეტში განთავსება (deploy)

მარტივი ვარიანტები: **Render**, **Railway**, ან საკუთარი VPS.
ფაილ-ბაზა (`data/shop.db`) უნდა იყოს მუდმივ დისკზე (persistent disk), რომ შეკვეთები არ წაიშალოს.

---

## Render-ზე გაშვება

რეპოში არის `render.yaml`, ამიტომ გაშვება ერთი ღილაკით ხდება:

1. გახსენი https://render.com/deploy?repo=https://github.com/nika-1991/sukula
2. შედი Render-ში GitHub ანგარიშით და მიეცი წვდომა `sukula` რეპოზე.
3. შეავსე ველები: `ADMIN_PASSWORD` (სავალდებულო), სურვილისამებრ `ORDER_EMAIL`, `SMTP_USER`, `SMTP_PASS`.
4. დააჭირე **Apply / Deploy**. რამდენიმე წუთში საიტი გაიხსნება მისამართზე `https://sukula-xxxx.onrender.com`.

ყოველი push `main`-ზე საიტს ავტომატურად განაახლებს.

**მნიშვნელოვანი (უფასო გეგმა):** უფასო სერვისის დისკი დროებითია. გადატვირთვისას ან ახალი
ვერსიის გაშვებისას `data/shop.db` თავიდან იქმნება: ადმინში შეცვლილი პროდუქტები და შენახული
შეკვეთები იკარგება (იმეილით გაგზავნილი შეკვეთები გრჩება). ასევე, 15 წუთი უმოქმედობის შემდეგ
სერვისი იძინებს და პირველი გახსნა ~1 წუთს სჭირდება. მუდმივი ბაზისთვის საჭიროა ფასიანი გეგმა
დისკით (იხ. კომენტარი `render.yaml`-ში).
